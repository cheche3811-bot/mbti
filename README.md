# 三维性格分析 · MBTI + 星座 + 生辰八字

卡通贴纸风的性格分析站。纯静态、零依赖、零构建，双击 `index.html` 即可运行。

从三个体系交叉看性格，**每条结论都标注来源依据**，并严格区分「实证研究支持」与「传统文化说法」。

## 两个入口

| 入口 | 用途 | 耗时 |
|---|---|---|
| **做 MBTI 测试** | 48 题七级量表，精准测出人格类型与各维度百分比 | 约 6 分钟 |
| **三维综合分析** | 已知类型直接填写，叠加星座与八字看交叉对比 | 约 30 秒 |

三个维度**任填 1–3 项**，输出内容按填写情况自动适配：单维度不做交叉，双维度做两两对比，三维度做完整交叉。

## 依据分级（核心设计）

所有结论在数据层都带 `evidence` 字段，**渲染时自动生成对应徽章**——不靠人工在文案里写声明，避免遗漏。

| 等级 | 含义 | 用于 |
|---|---|---|
| `empirical` | 同行评审实证研究 | 大五人格模型、MBTI→大五 映射系数 |
| `contested` | 有实证但存争议 | MBTI 类型学（重测信度约 50%） |
| `heuristic` | 启发式推导，未经验证 | 本项目的三维交叉映射设计 |
| `tradition` | 传统文化，无实证支持 | 星座性格、生辰八字 |
| `refuted` | 已被实证否证 | 占星预测效力（含《自然》双盲实验） |

共引用 **21 条文献**，全部登记在 `assets/data/sources.json`，结果页可展开查看。

## 三个维度

### 1. MBTI 人格分析
- 48 题七级李克特量表（-3 ~ +3），比二选一能捕捉倾向**强度**
- 每维度正反向题严格 5:5 平衡（AT 维度 4:4），抵消默认同意倾向
- 计分：`percent = (Σ(answer × direction) + max) / (2 × max) × 100`
- 45–58% 区间标注「倾向不明显」，不假装边界型是确定的
- 人口占比来自 CAPT 美国抽样统计

### 2. 星座性格分析
- 按黄道十二宫日期区间查表判定太阳星座
- 交界日（±1 天）**主动提示**可能偏差——太阳过黄经各宫起点的实际时刻每年浮动约 ±1 天
- 如实引用否证研究：Carlson (1985) 发表于《自然》的双盲实验、Dean & Kelly (2003) 时辰双生子追踪、Hartmann et al. (2006) 15000+ 样本检验
- 解释「为何感觉很准」：巴纳姆效应（Forer, 1949）

### 3. 生辰八字性格分析
- **日柱**：以 1900-01-31（儒略日 2415051）为甲辰日基准取模推算，此换算可独立验证
- **年柱**：以立春为界换年（命理惯例，非公历元旦）
- **月柱/时柱**：五虎遁 / 五鼠遁标准口诀
- **五行统计**：四柱天干地支各计权重，输出旺衰分布
- 日主（日柱天干）代表命主性格，源自《三命通会》《渊海子平》《滴天髓》
- 时辰可不填，将只排年月日三柱
- **已知局限**：未做真太阳时校正（经度时差 + 均时差），时柱为近似值；月柱按公历近似划分节气，交节前后 1–2 天可能有偏差

## 综合性格总结

三个维度融合后，生成一份**可以直接读的人格叙述**，包含：

| 内容 | 说明 |
|---|---|
| **人格原型** | 16 种原型（开拓型/架构型/定盘型/内省型…），由两条最突出的特质轴组合匹配 |
| **一句话概括** | 点明最鲜明的两个特点 |
| **整体叙述** | 按突出程度取 2–3 条特质轴，组合成连贯描述 |
| **做事 / 人际风格** | 分别对应工作场景与关系场景的行为倾向 |
| **优势 / 建议** | 每条挂在具体特质轴上，不是泛泛而谈 |
| **张力点** | 三维分歧对应的内在矛盾（如工作时与私下判若两人） |
| **可信度说明** | 按一致性水平给出不同的解读提示 |

文案库为**五轴 × 三档（高/中/低）× 五类 = 75 条**，按实际向量组合，不是固定模板。原型匹配率 86%（3125 种向量组合遍历），匹配不到时回退「均衡型」。

阈值：≥62 为高、≤38 为低、中间为居中。

## 动物拟物化头像（16 型）

另一套**动物形象**头像系统，参考网络流行的 MBTI 拟物化风格：INFJ 树精绿老头、INFP 做梦小蝴蝶、ENFP 快乐小狗、INTJ 深夜猫头鹰……

设计原则：**动物的行为特征 = 该型认知功能的具象表现**，不是随机搭配可爱动物。

- 512×512 / 128×128 两档尺寸，圆形 / 方形圆角两种裁切
- 四大群组色系区分，相邻群组色相间距 ≥46°
- 眉毛仅 T 型用、腮红仅 F 型用 —— 风格一致但可区分
- 导出：`node export-avatars.js` → 64 个 SVG 文件（单个约 2.6KB）

详见 [AVATAR-DESIGN.md](./AVATAR-DESIGN.md)（设定表与视觉规范）与 [AVATAR-PROMPTS.md](./AVATAR-PROMPTS.md)（AI 生成文案）。

## SVG 人形头像系统

**为什么不用 emoji**：emoji 在 iOS / Android / Windows 上字形完全不同，无法保证视觉一致，且在 Canvas 分享图里渲染质量不可控。

改为程序化 SVG 后：全平台完全一致、任意尺寸无损缩放、可参与 Canvas 绘制。

**参数化组合**：底色 + 脸型 + 发型（10 种）+ 眼睛（9 种）+ 嘴（7 种）+ 配饰（9 种），统一 `viewBox="0 0 100 100"`。

共 **55 个头像**：16 型人格 + 12 星座 + 10 天干 + 17 人格原型。

风格：厚描边 + 扁平色块 + 圆润造型。例如 INFP「调停者」是绿底 + 白胡子 + 温和垂眼的长者形象，ENFP 是橙发星星眼 + 腮红，INTP 戴眼镜 + 呆毛。

### 成就徽章

把数据转成可炫耀的社交货币，9 条规则动态解锁：

| 徽章 | 触发条件 |
|---|---|
| 💎 极稀有人格 | 人口占比 <2% |
| ✨ 稀有人格 | 人口占比 <4% |
| 🎯 三观高度统一 | 一致性 ≥85% |
| 🎭 多面人格 | 一致性 <45% |
| 🔥 某特质拉满 | 最高分 ≥76 |
| 🧊 极致某特质 | 最低分 ≤34 |
| 🏅 完整版报告 | 三维全填 |
| ⚖️ 罕见均衡型 | 五维跨度 ≤28 |

阈值不是凭感觉定的 —— 先跑 160 组真实数据看分布，再设条件。测试会验证**每条规则都能被真实数据触发**，防止出现永远解锁不了的死徽章。

### 分享文案

**5 类风格 × 28 套模板**，全部走「模板 + 变量插值」：

| 风格 | 思路 |
|---|---|
| 🔮 悬念式 | 不直接说结论，留钩子 |
| 💭 共鸣式 | 说出被说中的感受 |
| 😆 幽默式 | 自嘲降低炫耀味 |
| 🏆 成就炫耀式 | 突出稀有度与数据 |
| ◾ 极简式 | 配图发送，只做点题 |

**26 个变量**可插值：原型、动物形象、金句、一致性、稀有度、极值特质、优势建议、冲突轴、徽章……同一模板给不同用户看到的结果差异很大。

**三层筛选机制**：

```
1. 变量齐备 —— needs 声明的变量必须有值，否则跳过该模板
                （避免出现未替换的 {score} 占位符）
2. 长度预筛 —— 按插值后实际长度筛选，而非模板原文
                （与其截断毁掉文案，不如换一个短模板）
3. 轮换去重 —— localStorage 记录已用模板 ID，优先给没见过的
```

**平台长度适配**：朋友圈 120 字（112 字不折叠）、微博 140、小红书 200、极简 60。

### 扩展新模板

只改 `assets/data/share-copy.json`，不动任何 JS：

```jsonc
// 新增模板
{ "id": "sus-07", "text": "...{score}...", "needs": ["score"] }

// 新增风格
"styles": { "newStyle": { "name": "...", "icon": "...", "templates": [...] } }

// 新增徽章
{ "id": "xxx", "cond": "score>=90", "icon": "🌟", "label": "...", "weight": 99 }
```

改完跑 `node build-data.js` 重新打包。

`cond` 支持 `字段 比较符 数字`（如 `score>=85`）与裸布尔字段。**用自研的极简求值器，不用 eval** —— 避免数据文件成为代码注入点。

## 综合分析怎么算的

三个维度统一映射到 **大五人格（Big Five）五轴**：外向性 / 开放性 / 尽责性 / 宜人性 / 情绪稳定性。选大五作为公共坐标系，因为它是当代人格心理学中实证支持最充分的框架。

```
1. 三个维度各自映射到大五五轴
2. 向量以 50 为中心平移到 [-50,+50] 后计算余弦相似度
3. 相似度换算为一致性百分比，同轴差值 ≥30 标为分歧
```

**MBTI→大五 的映射有实测相关系数支持**（McCrae & Costa, 1989）：E-I 与外向性 r≈.74、S-N 与开放性 r≈.72、T-F 与宜人性 r≈.44、J-P 与尽责性 r≈.49。

**星座与八字→大五 的映射是语义归纳，无实证依据。**

### 一致性百分比该怎么理解

它衡量的是**三套性格描述在文字层面的吻合程度**，不是三种方法测量同一人格的收敛效度。高一致性只说明三套说法碰巧描述相近，**不代表结论更可靠**。

实测区分度（192 组 MBTI×星座）：最低 7%、中位 50%、平均 52%、最高 98%，分布接近正态——这个数字是真的在区分，不是摆设。

## 部署到 GitHub Pages

仓库已初始化并提交完毕，含 GitHub Actions 工作流。两步搞定：

**第1 步** — 在 GitHub 网页上新建一个空仓库（不要勾选 README / .gitignore / License），比如叫 `mbti`。

**第 2 步** — 回到本目录执行：

```bash
./deploy.sh <你的GitHub用户名> mbti
```

推送完成后，打开 `Settings → Pages`，把 **Source 设为「GitHub Actions」**（只需设置一次）。等1–2 分钟，站点上线：

```
https://<你的用户名>.github.io/mbti/
```

之后每次改完代码，`git add -A && git commit -m "..." && git push` 就会自动重新部署。

### 关于微信打开

- GitHub Pages 是 HTTPS + 公网域名，微信内可以打开
- 国内访问速度取决于网络环境，偶尔会慢
- `github.io` 域名未在国内备案，大规模传播时微信**有可能**提示风险或折叠。要彻底避免，需要自己的备案域名
- 已内置Open Graph 元信息，链接分享时会显示标题与描述卡片

### 其他托管选择

| 方案 | 国内速度 | 微信友好度 | 成本 |
|---|---|---|---|
| GitHub Pages | 一般 | 中| 免费 |
| Vercel / Netlify | 一般 | 中 | 免费 |
| 备案域名 + 对象存储 | 快 | 高 | 域名几十元/年 + 备案约1 周 |

整个项目是纯静态的，扔到任何静态托管都能跑。

## 设计语言

卡通贴纸风：
- 厚描边 `3px` + **硬阴影** `4px 4px 0`（不用模糊阴影，这是贴纸感的关键）
- 马卡龙配色，波点纹理背景
- 四大群组各有主色：分析家 `#9B7BEA` / 外交家 `#3FB98C` / 守护者 `#3F94D6` / 探险家 `#F2A63B`
- 七级量表用大小递变的圆点（30→15→30px），尺寸本身传达语义强度
