# 16 型人格测试 · MBTI

卡通贴纸风的 MBTI 人格测试站。纯静态、零依赖、零构建，双击 `index.html` 即可运行。

## 测评设计

不是随手点点的娱乐测试，计分模型上做了三件正经事：

| 项目 | 做法 | 为什么 |
|---|---|---|
| 题量 | 48 题 | EI/SN/TF/JP 各 10 题 + AT 身份维度 8 题 |
| 量表 | 七级李克特（-3 ~ +3） | 比二选一能捕捉倾向**强度**，而非只有方向 |
| 反向计分 | 每维度正反向题严格 5:5 平衡 | 抵消「默认同意倾向」(acquiescence bias) |
| 结果呈现 | 输出百分比 + 45~58% 标注「倾向不明显」 | 不假装边界型是确定的 |

计分公式：`percent = (Σ(answer × direction) + max) / (2 × max) × 100`

人口占比数据来自 CAPT（Center for Applications of Psychological Type）美国抽样统计，16 型总和 100.3%（舍入误差）。

## 功能

- **答题体验**：单选即自动跳下一题，支持键盘 `1`–`7` 快速作答、`←` 回退
- **结果报告**：五维度百分比条、认知功能栈（主导/辅助/第三/劣势）、天赋与成长空间、职业方向、同类型名人、互补配对
- **朋友圈分享图**：纯 Canvas 绘制 1080×1720 PNG，一键下载
- **隐私**：全程浏览器本地计算，不发任何网络请求

## 运行

直接双击 `index.html`，或起个本地服务：

```bash
cd mbti-test
python3 -m http.server 4173
# 打开 http://127.0.0.1:4173
```

## 部署到 GitHub Pages

仓库已初始化并提交完毕，含 GitHub Actions 工作流。两步搞定：

**第1 步** — 在 GitHub 网页上新建一个空仓库（不要勾选 README / .gitignore / License），比如叫 `mbti`。

**第 2 步** — 回到本目录执行：

```bash
./deploy.sh <你的GitHub用户名> mbti
```

推送完成后，打开 `Settings → Pages`，把 **Source 设为「GitHub Actions」**（只需设置一次）。等1–2 分钟，站点上线：

```
https://<你的用户名>.github.io/mbti/
```

之后每次改完代码，`git add -A && git commit -m "..." && git push` 就会自动重新部署。

### 关于微信打开

- GitHub Pages 是 HTTPS + 公网域名，微信内可以打开
- 国内访问速度取决于网络环境，偶尔会慢
- `github.io` 域名未在国内备案，大规模传播时微信**有可能**提示风险或折叠。要彻底避免，需要自己的备案域名
- 已内置Open Graph 元信息，链接分享时会显示标题与描述卡片

### 其他托管选择

| 方案 | 国内速度 | 微信友好度 | 成本 |
|---|---|---|---|
| GitHub Pages | 一般 | 中| 免费 |
| Vercel / Netlify | 一般 | 中 | 免费 |
| 备案域名 + 对象存储 | 快 | 高 | 域名几十元/年 + 备案约1 周 |

整个项目是纯静态的，扔到任何静态托管都能跑。

## 设计语言

卡通贴纸风：
- 厚描边 `3px` + **硬阴影** `4px 4px 0`（不用模糊阴影，这是贴纸感的关键）
- 马卡龙配色，波点纹理背景
- 四大群组各有主色：分析家 `#9B7BEA` / 外交家 `#3FB98C` / 守护者 `#3F94D6` / 探险家 `#F2A63B`
- 七级量表用大小递变的圆点（30→15→30px），尺寸本身传达语义强度

## 说明

本测试基于荣格心理类型理论与 MBTI 四维度模型设计。结果反映当下的行为偏好倾向，不是能力评价，也非临床诊断工具。
